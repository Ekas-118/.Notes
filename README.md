## Installation

### First-time installation

1. Download the `.cer` and `.msixbundle` files from the latest [Release](../../releases).
2. Double-click the `.cer` file → **Install Certificate** → **Current User**.
3. Double-click the `.msixbundle` file and click **Install**.

### Updating

1. Download the latest `.msixbundle` from [Releases](../../releases).
2. Double-click it and click **Install/Update**.

You only need to install the `.cer` certificate once. Updates require the same certificate and a higher version number.

# Minimum requirements:
**OS**: Windows 10 version 1809 (build 17763), or Windows 11
